Download CPU Manager

A Windows desktop app for CPU topology, per-process affinity, priority and ProBalance. Installers are per-user — no administrator rights, no reboot.

Windows may warn before the first run. Installers are not Authenticode-signed yet, so SmartScreen can show “Windows protected your PC”. Choose More info → Run anyway. Every release ships a SHA256SUMS.txt, so you can check the file before you run it.

Verify a download

Get-Content .\SHA256SUMS.txt
(Get-FileHash .\CPU-Manager_v0.1.0_windows-x64-setup.exe -Algorithm SHA256).Hash.ToLower()

The two hashes must match. If they do not, delete the file.

Upgrading

Installations of 0.1.1 and older look for updates in the project's previous repository and will never see a new release. Install 0.2.0 once by hand; the built-in updater takes over from there.

Download links come straight from the GitHub releases API, so they cannot drift from what is published. CPU Manager is MIT licensed.
